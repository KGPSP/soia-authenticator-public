# Zgłaszanie problemów bezpieczeństwa

Nie publikuj sekretów TOTP, bieżących kodów, kodów QR, nazw kont, danych osobowych, haseł, plików kopii ani informacji operacyjnych w publicznych Issues.

Zgłoszenie bezpieczeństwa wyślij na `informacje@kg.straz.gov.pl` z tematem:

`SOIA Authenticator — bezpieczeństwo`

Podaj wersję aplikacji i systemu, model telefonu, zwięzłe kroki odtworzenia oraz oczekiwane i faktyczne zachowanie. Używaj wyłącznie własnych danych syntetycznych. Nie dołączaj poufnych plików ani niezredagowanych zrzutów ekranu.

Publiczne repozytorium zawiera tylko kod statycznej witryny i zatwierdzone materiały. Kod aplikacji mobilnej nie jest publiczny.
